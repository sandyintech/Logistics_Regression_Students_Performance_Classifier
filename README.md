# Logistic Regression From Scratch

## Project Overview

This project implements Logistic Regression from scratch using Python and NumPy to predict whether a student will pass or fail based on study hours and previous exam scores.

## Objectives

* Understand the mathematical foundations of Logistic Regression.
* Implement the sigmoid activation function.
* Calculate binary cross-entropy (log loss).
* Train the model using gradient descent.
* Evaluate predictions using classification metrics.

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Jupyter Notebook

## Implementation

The project includes data exploration, feature selection, train-test splitting, feature standardization, weight and bias initialization, model training, and prediction. Training and test loss are tracked across epochs to monitor model performance.

## Evaluation

Model performance is assessed using accuracy, precision, recall, and a confusion matrix. Visualizations include training and test loss curves, a decision boundary plot, and a confusion matrix showing true positives, true negatives, false positives, and false negatives.

## Learning Outcomes

This project strengthens understanding of machine learning fundamentals by implementing the complete Logistic Regression workflow without using Scikit-learn for model training.

## Conclusion

A practical beginner-friendly project demonstrating how Logistic Regression learns from data and performs binary classification.
